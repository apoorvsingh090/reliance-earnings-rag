# Security Policy

## Supported Versions

Only the latest commit on `main` receives security fixes. This project
has no long-term-support branches.

## Reporting a Vulnerability

Please report security issues privately via
[GitHub Security Advisories](https://github.com/apoorvsingh090/reliance-earnings-rag/security/advisories)
("Report a vulnerability"). Do not open a public issue.

Reports that are especially appreciated:

- Dependency or supply-chain issues in ingestion, extraction, or UI code
- Secrets (API keys, cookies, upload data) leaking into logs, git history,
  or deployed artifacts
- Cross-site / request-forgery issues in web-facing apps

Out of scope: the accuracy of financial or market data shown, investment
outcomes, and issues in upstream APIs (NSE, Yahoo, Streamlit) themselves.

You will get an acknowledgement within 7 days. Fixes for accepted reports
land with credit in the `CHANGELOG.md` unless you prefer to stay anonymous.
